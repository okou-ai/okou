## Scenario value, public boundary and exact coverage losses

Memory freshness, avoiding duplicate billing and safe publication have product value. These selected declarations instead assert private scheduler choices, transaction outcomes, row shapes, forced historical/corrupt states or direct API-service returns. Normal chat/Runner completion may request daily work, but extraction/consolidation is driven by `cron-extract-pi-memory-stage1.ts` and `cron-consolidate-pi-memory-phase2.ts`, guarded by `hasValidCronSecret$`. That operator boundary does not permit these test-only claims or chosen state matrices. No independent normal-user API phase exists in the 34 unsupported declarations; delete them rather than adding an endpoint, time/polling hack or replacement private driver. This does not remove the production workers or certify unrelated route/worker tests.

One declaration (P1) is different: `piMemoryPhase2SelectionDigest` is an actual exported pure protocol function in `@okouai/pi-agent-runtime/api`, used by the API job/maintenance code and the runtime filesystem input builder. Its owning package already has independent golden tests. Preserve all three old vectors there (two already present, one extra parameter row); no DB/service/worker setup is relocated.
